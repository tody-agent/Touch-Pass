## 1. Разделение архитектуры: Прошивка vs. Локальный Хелпер

TouchPass спроектирован со строгим разделением обязанностей между **Аппаратной прошивкой (ESP32-S3)** и **Локальным Хелпером (ПО на ПК)** для обеспечения высокой производительности и безопасности биометрических учетных данных.

### Диаграмма потока данных архитектуры

```text
┌─────────────────────────┐
│ Сканер отпечатков       │ (Сканирование и сравнение ZW101)
│ (Датчик ZW101)          │
└────────────┬────────────┘
             │ UART Serial (Номер слота / Триггер IRQ)
             ▼
┌─────────────────────────┐
│ Прошивка ESP32-S3       │
│ (tiny_touch_keyboard)   │
└──────┬───────────▲──────┘
       │           │
  USB  │           │ Вывод USB Клавиатуры
Serial │           │ (Нажатия клавиш HID прямо в активное окно)
       ▼           │
┌──────────────────┴──────┐
│ Локальный Хелпер Python │ (run_portal_win.py / tinytouch_helper.py)
│ (http://127.0.0.1:8787) │
└────────────┬────────────┘
             │ Безопасный запрос пароля
             ▼
┌─────────────────────────┐
│ Хранилище паролей ОС    │ (Диспетчер учетных данных Windows / macOS Keychain)
└─────────────────────────┘
```

- **Прошивка ESP32-S3**: Отвечает за низкоуровневую связь с ZW101 по UART, управление светодиодами, проверку протокола HMAC-SHA256, расшифровку AES-CTR и эмуляцию аппаратной USB HID клавиатуры.
- **Служба локального хелпера**: Управляет локальным веб-сервером Web Portal HTTP, обрабатывает запросы на регистрацию отпечатков и безопасно извлекает пароли из хранилища текущего пользователя ОС (per-user helper Keychain / Credential Manager).

## 2. Обзор платформы TouchPass

Веб-портал TouchPass предоставляет удобный интерфейс по адресу `http://127.0.0.1:8787/` для управления 10 слотами биометрических отпечатков.

### Ограничения и правила действий
- **Максимальная длина действия**: Каждый слот поддерживает последовательность до **16 steps** или до **256 encoded bytes** (256 зашифрованных байт). Если длина превышает 256 байт, сохранение завершается ошибкой (save fails with reject error).
- **Защита подтверждением двойным касанием**: Пароли вводятся по одиночному касанию. Действия без паролей (Accept, Enter, Escape, пользовательские макросы) требуют касания того же пальца **дважды в течение 3 секунд** для предотвращения случайного запуска.

## 3. Пошаговый интерактивный мастер настройки

Веб-портал включает мастер из 4 шагов для первоначальной настройки:

1. **Шаг 1: Проверка USB HID клавиатуры** — Проверяет, что компьютер распознает ESP32-S3 как USB HID клавиатуру.
2. **Шаг 2: Проверка подключения оборудования** — Подтверждает связь по UART между ESP32-S3 и ZW101.
3. **Шаг 3: Регистрация первого отпечатка** — Регистрирует отпечаток пальца в Слот 01.
4. **Шаг 4: Назначение первого действия** — Назначает горячую клавишу или ввод пароля на зарегистрированный слот.

## 4. Интерактивный рекордер горячих клавиш

Веб-портал содержит интерактивный **Рекордер сочетаний клавиш**:
- Нажмите любую физическую клавишу или комбинацию с модификаторами (`Ctrl`, `Shift`, `Alt/Option`, `Cmd/Meta`).
- Рекордер автоматически перехватывает скан-коды и маску модификаторов.
- Нажмите **Save Action** для загрузки макроса на устройство.

## 6. Консоль отладки и логи событий в реальном времени

Веб-портал содержит консоль логов событий в реальном времени:
- 🟢 `TOUCH`: Обнаружено касание датчика.
- 🔵 `MATCH`: Отпечаток совпал с сохраненным слотом.
- 🔑 `PW`: Пароль извлечен из хранилища и введен.
- 🔴 `ERR`: Ошибка или недействительная подпись HMAC.
- ⚪ `SYS`: Обновление статуса системы.

## 7. Чек-лист безопасности

- **Безопасность сфокусированного окна**: TouchPass работает как обычная USB HID клавиатура. Символы вводятся в активное сфокусированное окно приложения. Всегда проверяйте позицию курсора перед касанием датчика.
- **Хранение паролей**: Пароли сохраняются локальным хелпером в системном хранилище ОС (Windows Credential Manager / macOS Keychain).
- **Ограничения разблокировки сессии**: TouchPass поддерживает разблокировку текущей сессии пользователя (session unlock). Устройство НЕ поддерживает разблокировку при холодной загрузке FileVault (cold boot) или после выхода из системы (after logout), так как службы хелпера и Keychain заблокированы до входа пользователя в сессию.

## 8. Устранение неполадок

| Симптом | Причина | Решение |
| :--- | :--- | :--- |
| Портал показывает `Disconnected` | Последовательный порт не открыт | Проверьте USB-кабель и убедитесь, что `USB CDC On Boot` включен в прошивке. |
| Светодиод датчика выключен | Проблема с питанием | Проверьте подключение `V_TOUCH` и `VCC` к шине `3V3`. |
| Ошибка сохранения действия | Превышен лимит | Убедитесь, что макрос содержит не более 16 steps и 256 encoded bytes. |
