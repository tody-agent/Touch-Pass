# Сборка и настройка TouchPass

[🌐 **English**](BUILD_GUIDE.md) | [🇻🇳 **Tiếng Việt**](BUILD_GUIDE.vi.md) | [🇨🇳 **简体中文**](BUILD_GUIDE.zh.md) | 🇷🇺 **Русский**

Настоящее руководство поможет вам пройти путь от отдельных компонентов до работающего локального портала TouchPass на Windows или macOS.
Выполняйте шаги из корневой директории данного репозитория (папка, содержащая `README.md`). TouchPass является удобным устройством ввода USB HID клавиатуры, а не абсолютным рубежом безопасности: оно вводит данные в любое текущее активное (сфокусированное) окно на вашем компьютере, а соединение датчика представляет собой незащищенную линию UART (unauthenticated UART).

## Что вы собираете

Вы подключите сканер отпечатков пальцев ZW101 к микроконтроллеру ESP32-S3 Super Mini, прошьете [прошивку TouchPass](../firmware/tiny_touch_keyboard/tiny_touch_keyboard.ino), а затем запустите локальную службу и веб-портал (`http://127.0.0.1:8787/`). Портал управляет слотами отпечатков с 1 по 10 и назначает действия зарегистрированным пальцам. Парольные действия сохраняются хелпером в системном хранилище ОС (Диспетчер учетных данных Windows / macOS Keychain); прошивка и хелпер используют общий парный ключ для проверки подлинности и шифрования сообщений по USB CDC.

![Схема компонентов TouchPass](../assets/demo/05-exploded-view-v3.png)

Изображение выше является **концептуальным рендером (conceptual render)**, а не сборочным чертежом или шаблоном для резки. Репозиторий **не содержит файлов CAD**, соответствующих данному корпусу. Измеряйте ваши реальные плату, датчик, кабель и корпус; модули с одинаковым названием могут отличаться по размерам.

## Компоненты и инструменты

- ESP32-S3 Super Mini (прошивка также поддерживает Waveshare ESP32-S3-Zero в качестве совместимой платы).
- Сканер отпечатков пальцев ZW101 с 6-контактным шлейфом.
- Корпус для проекта размером примерно **80 × 50 × 32 mm**. Проверьте его *внутренние* размеры перед покупкой или резкой.
- Как минимум семь соединительных проводов DuPont (безопасных для 3.3 V) и небольшая макетная плата (breadboard) для первого теста на столе: шесть проводов для датчика и один для общей шины 3V3 (3V3 fan-out junction). Для постоянного монтажа используйте короткие многожильные монтажные провода.
- Термоусадочные трубки для каждого паяного соединения и резиновая втулка или зажим для защиты кабеля от натяжения.
- Небольшой клеммник или макетная плата для разводки шины 3V3 (3V3 junction / split). Паяное тройное соединение при полной изоляции также подойдет.
- Кабель USB для **передачи данных** для ESP32-S3; многие кабели только для зарядки не способны передавать прошивку или последовательный порт.
- Компьютер (Windows 10/11, macOS или Linux) с установленным Arduino IDE или `arduino-cli`, Python 3.9+ и подключением к интернету.
- Линейка или штангенциркуль, малярный скотч, маркер, дрель со сверлами, инструмент для вырезания отверстий, надфиль и защитные очки.
- Для пайки: паяльник с регулировкой температуры, припой, стриппер, кусачки и мультиметр.

Отключайте питание от датчика и платы при выполнении любых соединений.

## Схема подключения (Wiring)

Оба вывода питания ZW101 используют логику и напряжение 3.3 V. **Никогда не подключайте VCC ZW101 или сигналы UART к напряжению 5 V.** Сигналы TX и RX подключаются перекрестно: TX датчика идет на RX платы ESP32, а RX датчика — на TX платы ESP32.

| ZW101 | ESP32-S3 Super Mini |
| --- | --- |
| V_TOUCH (pin 1) | 3V3 |
| TouchOut (pin 2) | GPIO1 |
| VCC (pin 3) | 3V3 |
| TX (pin 4) | GPIO6 / ESP RX |
| RX (pin 5) | GPIO7 / ESP TX |
| GND (pin 6) | GND |

`V_TOUCH` и `VCC` — это отдельные выводы датчика, и **обоим требуется 3V3**. Если у вашей платы только один вывод `3V3`, сделайте изолированное тройное соединение (3V3 fan-out junction): один провод от `3V3` платы разветвляется на два провода к `V_TOUCH` и `VCC`. Используйте пайку, полностью закрытую термоусадкой, или клеммник. Для первого теста можно использовать шину макетной платы. Не скручивайте оголенные провода скотчем. При отключенном USB проверьте мультиметром в режиме прозвонки, что оба вывода питания датчика соединены с `3V3` и отсутствует короткое замыкание на `GND`.

Не заменяйте выводы GPIO0, GPIO3, GPIO45 или GPIO46 на ESP32-S3 другими назначениями. Прошивка использует указанную выше распиновку и обменивается данными с датчиком на скорости 57 600 бод.

## Сборка

### Тестирование платы на столе

Выполните первую прошивку и проверку портала без корпуса. Это самый простой способ обнаружить ошибки в подключении до начала резки корпуса.

1. Отключив USB, соберите изолированное разветвление 3V3 и подключите все шесть контактов датчика в точном соответствии с таблицей.
2. Проверьте еще раз, что `V_TOUCH` и `VCC` подключены к `3V3`, а не к `5V`, TX/RX подключены перекрестно, а оголенные провода не касаются соседних контактов.
3. Положите плату и датчик на чистую диэлектрическую поверхность.
4. Подключите только кабель USB data к ESP32-S3. Компьютер питает плату через USB; не подключайте отдельный источник 5 V к ZW101.
5. Переходите к разделам **Прошивка**, **Запуск хелпера и портала** и физической проверке.

### Установка в корпус

Начинайте работу с корпусом только после успешного прохождения настольного теста.

1. Измерьте фактические размеры платы, датчика, разъема USB и радиус изгиба проводов.
2. Разместите датчик так, чтобы палец свободно прикладывался к плашке. Разместите ESP32-S3 так, чтобы разъем USB выходил к краю корпуса.
3. Заклейте внешние поверхности корпусной детали малярным скотчем и разметьте отверстия.
4. Извлеките все электронные компоненты перед сверлением и резкой.
5. Зачистите заусенцы. Выполните примерку.
6. Закрепите детали стойками или изолирующим клеем. Предусмотрите защиту кабеля от натяжения (strain relief).
7. Изолируйте все паяные соединения термоусадкой, повторите проверку мультиметром, закройте корпус и только после этого подсоедините USB.

## Подготовка компьютера (macOS / Linux / Windows)

В терминале перейдите в корень репозитория, создайте виртуальное окружение Python и установите зависимости:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r software/macos-helper/requirements.txt
```

Перед настройкой выполните автоматические проверки файлов:

```bash
test -f firmware/tiny_touch_keyboard/tiny_touch_keyboard.ino
test -f firmware/tiny_touch_keyboard/secrets.example.h
test -f software/macos-helper/requirements.txt
test -f software/macos-helper/tinytouch_helper.py
```

## Создание парного ключа (Pairing Key)

Эта процедура выполняется **только один раз (first-time only)**. Не запускайте её повторно в качестве шага восстановления. По умолчанию идентификатор хелпера в Keychain — аккаунт `B8F862FB478C` в службе `tinyTouch-pairing`.

Выполните блок команд из корня репозитория. Перед созданием он проверяет наличие `secrets.h` и существующей записи в Keychain. Если любой из них существует, выводится `STOP`, и замена не производится. Команда `cp -n` обеспечивает защиту от перезаписи.

```bash
(
  pairing_device_id="B8F862FB478C"
  pairing_service="tinyTouch-pairing"
  secrets_file="firmware/tiny_touch_keyboard/secrets.h"
  pairing_conflict=0

  if [ -e "$secrets_file" ]; then
    printf 'STOP: %s already exists; it was not overwritten.\n' \
      "$secrets_file" >&2
    pairing_conflict=1
  fi

  if security find-generic-password -a "$pairing_device_id" \
    -s "$pairing_service" >/dev/null 2>&1; then
    printf 'STOP: Keychain pairing item %s/%s already exists.\n' \
      "$pairing_service" "$pairing_device_id" >&2
    pairing_conflict=1
  fi

  if [ "$pairing_conflict" -ne 0 ]; then
    printf 'Use the intentional rotation instructions below only when needed.\n' >&2
    exit 1
  fi

  cp -n firmware/tiny_touch_keyboard/secrets.example.h "$secrets_file" || exit 1
  pairing_key="$(openssl rand -hex 32)" || exit 1
  printf 'Copy this C++ byte list into secrets.h:\n'
  printf '%s' "$pairing_key" | sed 's/../0x&, /g'
  printf '\n'

  if ! .venv/bin/python software/macos-helper/tinytouch_helper.py \
    --device-id "$pairing_device_id" --set-pairing-key "$pairing_key"; then
    unset pairing_key
    exit 1
  fi
  unset pairing_key
)
```

Блок выводит список байтов C++, сохраняет ключ в Keychain и очищает переменную с помощью `unset pairing_key`. Хелпер подтверждает сохранение сообщением: `pairing key stored in Keychain`.

Откройте `firmware/tiny_touch_keyboard/secrets.h`. Замените 32 значения `0x00` в массив `PAIRING_KEY` на выведенные байты. Файл `secrets.h` игнорируется Git и не должен передаваться никому.

### Плановая ротация парного ключа (Pairing-Key Rotation)

Не удаляйте файлы вручную для повторного запуска первого блока. Для ротации ключа (rotation) нужно обновить **и macOS Keychain, и существующий `secrets.h` новым ключом, а затем повторно прошить устройство (reflash)**.

Остановите хелпер. Сгенерируйте новый ключ:

```bash
pairing_key="$(openssl rand -hex 32)"
printf '%s' "$pairing_key" | sed 's/../0x&, /g'
printf '\n'
```

Обновите массив байтов в `secrets.h`, обновите Keychain и очистите переменную:

```bash
.venv/bin/python software/macos-helper/tinytouch_helper.py \
  --device-id B8F862FB478C --set-pairing-key "$pairing_key"
pairing_result=$?
unset pairing_key
[ "$pairing_result" -eq 0 ]
```

Сразу же скомпилируйте и прошейте плату заново.

## Настройка Arduino

1. Установите Arduino IDE 2 с [официального сайта](https://www.arduino.cc/en/software).
2. Откройте **Tools → Board → Boards Manager**, найдите `esp32` от **Espressif Systems**, выберите версию **3.3.11** и нажмите **Install**.

Откройте скетч [tiny_touch_keyboard.ino](../firmware/tiny_touch_keyboard/tiny_touch_keyboard.ino) в Arduino IDE. Выберите параметры:

| Настройка Arduino | Значение |
| --- | --- |
| Board | `ESP32S3 Dev Module` |
| USB Mode | `USB-OTG (TinyUSB)` |
| USB CDC On Boot | `Enabled` |
| Flash Size | `4MB` |
| PSRAM | `Disabled` |

### Вариант A: Использование `arduino-cli` (Командная строка)

Компиляция и прошивка через `arduino-cli`:

```bash
# Компиляция прошивки
arduino-cli compile --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc,UploadMode=cdc firmware/tiny_touch_keyboard

# Прошивка (Пример COM-порта Windows)
arduino-cli upload -p COM3 --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc,UploadMode=cdc firmware/tiny_touch_keyboard

# Прошивка (Пример для macOS)
arduino-cli upload -p /dev/cu.usbmodem101 --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc,UploadMode=cdc firmware/tiny_touch_keyboard
```

### Вариант B: Использование графического интерфейса Arduino IDE

1. В Arduino IDE нажмите **Verify** (Проверить).
2. Нажмите **Upload** (Загрузить) и дождитесь окончания процесса.


Откройте [http://127.0.0.1:8787](http://127.0.0.1:8787) в браузере.

## Устранение неполадок

| Симптом | Проверка |
| --- | --- |
| Хелпер сообщат, что ESP32-S3 USB CDC устройство не найдено | Используйте кабель USB Data, переподключите плату, убедитесь, что `USB CDC On Boot` включен. |
| Arduino не может загрузить прошивку | Проверьте порт и настройки платы. Для Waveshare ESP32-S3-Zero используйте кнопки BOOT/RESET. |
| Датчик недоступен | Проверьте соединение TX->GPIO6, RX->GPIO7, питание 3V3 и общую землю GND. |
| Распознанный палец не выполняет действие | Убедитесь, что `secrets.h` и Keychain используют одинаковый ключ шифрования. |

Руководство на английском языке доступно в файле [`BUILD_GUIDE.md`](BUILD_GUIDE.md).
