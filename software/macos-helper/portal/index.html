Chào mừng đến với TouchPass

Hoàn thành 3 bước bên dưới để cài đặt và trải nghiệm thiết bị xác thực vân tay USB HID TouchPass.

Bước 1

Test USB HID Keyboard Output

TouchPass giả lập bàn phím USB HID phần cứng. Nhấp vào ô văn bản bên dưới và nhấn nút thử nghiệm để kiểm tra tính năng mô phỏng phím gõ.

Bước 2

Hướng dẫn đấu nối phần cứng ZW101

Sơ đồ kết nối giữa vi điều khiển ESP32-S3 và cảm biến vân tay ZW101:

Cảm biến ZW101 Chân ESP32-S3 Ghi chú
VCC 3.3V Nguồn cấp cảm biến
GND GND Mass chung
TX RX (GPIO 18) Truyền dữ liệu Serial
RX TX (GPIO 17) Nhận dữ liệu Serial
Touch / IRQ GPIO 15 Tín hiệu ngắt cảm ứng
Bước 3

Đăng ký vân tay & Cấu hình Slot

TouchPass hỗ trợ lưu trữ tới 10 mẫu vân tay. Mỗi ngón tay tương ứng với một hành động (nhập mật khẩu, phím Enter, phím Escape, hoặc macro văn bản tùy chỉnh).

Chạm kép bảo vệ thao tác xác nhận. Password chạy sau một lần chạm; Accept, Enter, Escape và macro tùy chỉnh cần chạm lại cùng ngón trong 3 giây.

Hướng dẫn sử dụng & Kịch bản mẫu

Khám phá các kịch bản tự động hóa phổ biến được tối ưu cho TouchPass.

🖥️

Terminal Sudo

Nhập mật khẩu administrator tự động khi chạy lệnh sudo trong macOS Terminal hoặc iTerm2.

Preset: Mật khẩu + Enter Chạm 1 lần -> Tự động điền mật khẩu & gửi phím Enter
🔀

Git Commit 'y/N'

Xác nhận câu hỏi 'y/N' trên Terminal khi commit code hoặc push git với chế độ chạm kép an toàn.

Preset: Accept (Y + Enter) Chạm lần 1 -> Chờ chạm xác nhận trong 3s Chạm lần 2 -> Gửi 'y' + Enter
⚙️

Custom Macro

Chuỗi hành động kết hợp giữa gõ chữ ASCII, phím Tab/Enter và khoảng hoãn delay thời gian tùy chỉnh.

Preset: Macro tùy chỉnh Bước 1: Text 'admin' -> Bước 2: Key 'Tab' -> Bước 3: Delay 250ms -> Bước 4: Key 'Enter'
🔐

Password Autofill

Điền mật khẩu bảo mật dài, phức tạp lưu trong Keychain một cách chính xác mà không lo bị lộ phím.

Preset: Mật khẩu + Enter Lưu trữ an toàn trong macOS Keychain / Chạm ngón tay trỏ để đăng nhập ngay lập tức
